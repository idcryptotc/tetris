# 🧱 Тетрис

Консольный Тетрис на **C++23** для Windows. Без внешних зависимостей — только WinAPI и стандартная библиотека.

```
        ┌────────┐
        │        │
        │   ██   │
        │   ██   │
        │        │
        │ ██  ██ │
        │ ██  ██ │
        └────────┘
```

## ✅ Что уже есть

- **Одиночная игра** — 7 классических фигур, очки, 25 уровней сложности (скорость растёт).
- **Предпросмотр следующей фигуры** и панель счёта/уровня.
- **Переназначение клавиш** — интерактивное меню настройки, сохраняется в `tetris_settings.ini`.
- **Двойная буферизация** — отрисовка без мерцания (чтение основного буфера → запись в резервный → переключение активного).
- **16-цветная палитра** консоли.

## 🎮 Управление

| Действие | Клавиша по умолчанию |
|---|---|
| Влево | `←` |
| Вправо | `→` |
| Поворот против часовой стрелки | `↑` |
| Поворот по часовой стрелке | `↓` |
| Ускорение падения | `Пробел` |
| Выход в меню | `Esc` |

Все клавиши можно переназначить в меню настроек (пункт **2** главного меню). Назначения сохраняются между запусками.

## 📁 Структура проекта

| Файл | Назначение |
|---|---|
| `Main.cpp` | Точка входа: `main()` — инициализация, загрузка настроек, цикл меню/партий |
| `Tetris.h` / `Tetris.cpp` | Игровой цикл, ввод; `Tetris.h` — объявление `PlayGame()` |
| `Console.h` / `Console.cpp` | Консоль: инициализация (`ProgramSettings()`), двойная буферизация (`DoubleBufferingBegin/End`) |
| `Game.h` / `Game.cpp` | Правила игры: столкновения, движения, падение, очистка линий, счёт и уровни |
| `GameField.h` / `GameField.cpp` | Рендер поля: сборка кадра (`CreateGameField`) и вывод в консоль (`ViewGameField`) |
| `GameMenu.h` / `GameMenu.cpp` | Меню: главное меню (`StartMenu`), возврат из игры (`ReturnToMenu`), очистка буфера клавиатуры (`ClearKeyboardBuffer`) |
| `Figure.h` / `Figure.cpp` | Класс `Figure` — падающая фигура: позиция, поворот, сдвиги |
| `FigureGenerator.h` / `FigureGenerator.cpp` | Генерация фигур: случайный id (`RandomFigureId`) и стартовая позиция (`PositionById`) |
| `GameData.h` | Константы, таблицы фигур, энамы, раскладка поля (namespace `Tetris`) |
| `Keys.h` | Виртуальные коды клавиш, действия, набор привязок |
| `Settings.h` | Загрузка/сохранение настроек, интерактивная настройка клавиш |

## 🔧 Технологии

- **C++23** — `inline constexpr`, `inline`-функции в заголовках (header-only модули настроек).
- **WinAPI** — консольные буферы, `GetAsyncKeyState` для опроса клавиатуры.
- **Без внешних зависимостей** — только стандартная библиотека и Windows SDK.

## 🗺️ Дорожная карта

### 🎨 Заставки
Настоящая графика в консоли: **truecolor (24 бита)** через VT-последовательности + половинные блоки `▀ ▄ █` (двойное вертикальное разрешение). Пиксель-арт без внешних зависимостей.

### 🎵 Музыка
Два слоя, выбор по формату файла:

- **MCI** — MIDI (классика, системный секвенсор Windows, без зависимостей).
- **miniaudio** — MP3 / FLAC / OGG / WAV (один заголовок, MIT, поверх WASAPI).

### 👥 Два игрока
Одновременная игра на одной клавиатуре (удобные раскладки подберём по ходу). Поддержка геймпадов через **XInput** — единый API для Xbox, DualShock 4 и большинства USB-падов.

### 🌐 Сетевой режим
Игра на двоих по сети. Протокол: обмен **ходами** (движение / поворот / сброс) по **TCP** — мало трафика, просто. *Самое сложное — берём последним.*
