# 🧱 Тетрис

Консольный Тетрис на **C++23** для Windows. Без внешних зависимостей — только WinAPI и стандартная библиотека.

## ✅ Что уже есть

- **Одиночная игра** — 7 классических фигур, очки, 25 уровней сложности (скорость растёт).
- **Условие победы** — достижение 25-го уровня (счёт 8000) → экран «YOU WIN»; переполнение стека → «GAME OVER».
- **Экраны конца партии** — пиксельные «GAME OVER» / «YOU WIN» (пиксельный шрифт на половинных блоках `▀ ▄ █` — квадратные пиксели), счёт/уровень, «Для выхода в меню нажми Enter».
- **Вспышка level up** — баннер «LEVEL N» поверх поля (без паузы), гаснет, когда фигура прошла треть поля.
- **Заставка при запуске** — логотип «TETRIS» и ряд фигур, пиксель-арт на половинных блоках `▀ ▄ █` (квадратные пиксели, двойное вертикальное разрешение), висит до нажатия любой клавиши.
- **Предпросмотр следующей фигуры** и панель счёта/уровня.
- **Меню на пиксельном шрифте** — заголовок «МЕНЮ» и пункты (главное меню и возврат из игры) рисуются кириллическими глифами 5×7 на половинных блоках `▀ ▄ █` (как логотип заставки), выбор — цифрами 1–3.
- **Переназначение клавиш** — интерактивное меню настройки, сохраняется в `tetris_settings.ini`.
- **Отрисовка без мерцания** — двойная буферизация в обоих режимах: кадр рисуется в скрытый буфер, затем атомарно переключается активный буфер (в фиксированном — копирование основного буфера в резервный, в адаптивном — показ предыдущего кадра в резервном и рисование нового в основном).
- **Два режима консоли** — фиксированные 80×25 (классическая консоль, через `mode con`) и адаптивный (Windows Terminal и другие терминалы с псевдоконсолью: кадр 80×25 центрируется в окне, при слишком маленьком окне — окно-подсказка, заставка пропускается). Режим определяется автоматически при запуске.
- **Цвета** — truecolor (24 бита, классическая палитра Tetris) в Windows Terminal; 16-цветная палитра в классической консоли (conhost).
- **MCP / агент** — LLM-агент (через MCP-клиент) играет в Тетрис сам: режим `--agent` (агентский канал на TCP `127.0.0.1:7777`–`7786`) + MCP-сервер `--mcp-server` (stdio, спецификация MCP) — раздел «🤖 MCP / агент».

## 🎮 Управление

| Действие | Клавиша по умолчанию |
|---|---|
| Влево | `←` |
| Вправо | `→` |
| Поворот против часовой стрелки | `↑` |
| Поворот по часовой стрелке | `↓` |
| Ускорение падения | `Пробел` |
| Выход в меню | `Esc` |

Все клавиши можно переназначить в меню настроек (пункт **2** главного меню). Назначения сохраняются между запусками.

В меню паузы `Esc` — то же, что пункт **2** («Продолжить»).

## 🤖 MCP / агент

Агент (LLM через MCP-клиент) играет в Тетрис сам: его ходы видны на игровом поле и идут через тот же движок, что и клавиатура.

**Запуск** (два режима, один исполняемый файл):

1. `Tetris.exe --agent` — игра в агентском режиме: без заставки и меню, сразу в партию; ввод с клавиатуры игнорируется. Агентский канал слушает TCP `127.0.0.1`, порт `7777` (при занятости — `7778`…`7786`, первый свободный).
2. `Tetris.exe --mcp-server` — MCP-сервер (stdio, JSON-RPC 2.0, спецификация MCP). Отдельный процесс: сам подключается к игре, запущенной с `--agent`, и проксирует вызовы тулзов.

Игру с `--agent` нужно запустить **до** подключения MCP-клиента к серверу. После game over игра не ждёт Enter — ждёт команду `restart` от агента. Темп в агентском режиме фиксированный — **40 секунд на фигуру** (не зависит от уровня): агенту нужно время на «раздумья» (MCP-раундтрип занимает секунды), а темп игры для человека ему не подходит.

**Конфигурация MCP-клиента** (стандартный формат `command` + `args`; работает с любым MCP-клиентом: LM Local, Claude Desktop, VS Code):

```json
{
  "mcpServers": {
    "tetris": {
      "command": "Tetris.exe",
      "args": ["--mcp-server"]
    }
  }
}
```

**Тулзы:**

| Тулз | Действие |
|---|---|
| `get_state` | Состояние партии: поле (10×22 сетка, буква — фигура), текущая и следующая фигуры (клетки в координатах поля), счёт, уровень, game over / победа |
| `get_rules` | Правила Тетриса и формат состояния — для агента, который не знает правил |
| `move_left` / `move_right` | Сдвинуть текущую фигуру на 1 колонку влево / вправо |
| `rotate_up` / `rotate_down` | Повернуть текущую фигуру против / по часовой стрелке |
| `hard_drop` | Мгновенно опустить текущую фигуру до фиксации |
| `restart` | Начать новую партию (после game over / победы) |
| `quit` | Завершить игру (процесс `Tetris.exe`) |

Состояние в `get_state` адаптировано под LLM: поле — человекочитаемая сетка 22 строки × 10 символов (`.` — пусто, `A`–`G` — id фигуры), фигуры — клетки `[x, y]` в координатах поля. Внутренний формат стека (21 колонка, клетка = 2 колонки) агенту не показывается.

## 📁 Структура проекта

```
Tetris/
├─ Main.cpp              ← точка входа
├─ Core/                 ← игровая логика: Tetris, Game, Figure,
│                          FigureGenerator, GameData, TetrisEngine
├─ Rendering/            ← рендер: Console, GameField, Splash,
│                          GameEnd, PixelFont
├─ Input/                ← ввод и настройки: Keys, Settings
├─ Menu/                 ← меню: GameMenu
└─ Agent/                ← агентский режим и MCP-сервер: AgentGame,
                           AgentChannel, AgentGameSession, McpServer, Json
```

| Файл | Назначение |
|---|---|
| `Main.cpp` | Точка входа: `main()` — инициализация, загрузка настроек, заставка, цикл меню/партий; флаги `--agent` / `--mcp-server` |
| `Core/Tetris.h` / `Core/Tetris.cpp` | Игровой цикл, ввод поверх движка; `Tetris.h` — объявление `PlayGame()` |
| `Core/TetrisEngine.h` / `Core/TetrisEngine.cpp` | Игровой движок без I/O: состояние партии, `Reset()`, `BeginFigure()`, `FallOneStep()`, `PrepareLineClear()`/`CommitLineClear()`, `ApplyAction()`, `GetState()` — общий путь для клавиатуры и агента |
| `Rendering/Console.h` / `Rendering/Console.cpp` | Консоль: инициализация (`ProgramSettings()`), определение режима (фиксированный 80×25 / адаптивный для Windows Terminal и других pty-терминалов), двойная буферизация (`DoubleBufferingBegin/End`) |
| `Core/Game.h` / `Core/Game.cpp` | Правила игры: столкновения, движения, падение, очистка линий, счёт и уровни |
| `Rendering/GameField.h` / `Rendering/GameField.cpp` | Рендер поля: сборка кадра (`CreateGameField`) и вывод в консоль (`ViewGameField`) |
| `Rendering/Splash.h` / `Rendering/Splash.cpp` | Заставка при запуске: логотип «TETRIS» + ряд фигур, пиксель-арт на половинных блоках `▀ ▄ █` (квадратные пиксели), висит до нажатия любой клавиши (`ShowSplash`) |
| `Rendering/GameEnd.h` / `Rendering/GameEnd.cpp` | Экраны конца партии: «GAME OVER» (`ShowGameOver`) и «YOU WIN» (`ShowWin`) — пиксельное сообщение на половинных блоках + счёт/уровень, ожидание Enter |
| `Rendering/PixelFont.h` | Пиксельный шрифт 5×7: латиница A–Z, цифры 0–9, дефис, кириллица (33 буквы) — логотип заставки, экраны конца партии, меню |
| `Menu/GameMenu.h` / `Menu/GameMenu.cpp` | Меню на пиксельном шрифте (кириллица): главное меню (`StartMenu`), возврат из игры (`ReturnToMenu`), очистка буфера клавиатуры (`ClearKeyboardBuffer`) |
| `Core/Figure.h` / `Core/Figure.cpp` | Класс `Figure` — падающая фигура: позиция, поворот, сдвиги |
| `Core/FigureGenerator.h` / `Core/FigureGenerator.cpp` | Генерация фигур: случайный id (`RandomFigureId`) и стартовая позиция (`PositionById`) |
| `Core/GameData.h` | Константы, таблицы фигур, энамы, раскладка поля (namespace `Tetris`) |
| `Input/Keys.h` | Виртуальные коды клавиш, действия, набор привязок |
| `Input/Settings.h` | Загрузка/сохранение настроек, интерактивная настройка клавиш |
| `Agent/AgentGame.h` / `Agent/AgentGame.cpp` | Агентский режим (`--agent`): игра без ввода с клавиатуры, ходы — из агентского канала |
| `Agent/AgentChannel.h` / `Agent/AgentChannel.cpp` | Агентский канал: TCP-сервер на `127.0.0.1` (WinAPI-сокеты), фоновый поток, протокол «строка = JSON» |
| `Agent/AgentGameSession.h` / `Agent/AgentGameSession.cpp` | Обмен между игровым циклом и каналом: очередь действий, снимок состояния, флаги (под мьютексом) |
| `Agent/McpServer.h` / `Agent/McpServer.cpp` | MCP-сервер (`--mcp-server`): stdio JSON-RPC 2.0 по спецификации MCP, проксирует тулзы в агентский канал игры |
| `Agent/Json.h` / `Agent/Json.cpp` | Минимальный JSON (значение, парсер, сериализатор) — без внешних зависимостей |

## 🔧 Технологии

- **C++23** — `inline constexpr`, `inline`-функции в заголовках (header-only модули настроек).
- **WinAPI** — консольные буферы, `GetAsyncKeyState` для опроса клавиатуры.
- **Truecolor (24 бита)** — VT-последовательности (`ESC[38;2;R;G;Bm`) в Windows Terminal (адаптивный режим); в классической консоли (conhost) — 16-цветная палитра.
- **Без внешних зависимостей** — только стандартная библиотека и Windows SDK.

## 🗺️ Дорожная карта

### 🎨 Заставки — ✅ завершено
- **Титульная заставка** — логотип «TETRIS» + ряд фигур: пиксель-арт на половинных блоках `▀ ▄ █` (квадратные пиксели, двойное вертикальное разрешение), в Windows Terminal — truecolor (24 бита).
- **Финальные экраны** — «GAME OVER» / «YOU WIN» переведены на половинные блоки (квадратные пиксели).
- **Меню глифами** — заголовок и пункты меню на пиксельном шрифте, **на русском** (кириллические глифы), на половинных блоках.

### 🎵 Музыка
Два слоя, выбор по формату файла:

- **MCI** — MIDI (классика, системный секвенсор Windows, без зависимостей).
- **miniaudio** — MP3 / FLAC / OGG / WAV (один заголовок, MIT, поверх WASAPI).

### 👥 Два игрока
Одновременная игра на одной клавиатуре (удобные раскладки подберём по ходу). Поддержка геймпадов через **XInput** — единый API для Xbox, DualShock 4 и большинства USB-падов.

### 🌐 Сетевой режим
Игра на двоих по сети. Протокол: обмен **ходами** (движение / поворот / сброс) по **TCP** — мало трафика, просто. *Самое сложное — берём последним.*
