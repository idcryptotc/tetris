# 🧱 Тетрис

Консольный Тетрис на **C++23** для Windows. Без внешних зависимостей — только WinAPI и стандартная библиотека.

```
        ┌────────┐
        │        │
        │   ██   │
        │   ██   │
        │        │
        │ ██  ██ │
        │ ██  ██ │
        └────────┘
```

## ✅ Что уже есть

- **Одиночная игра** — 7 классических фигур, очки, 25 уровней сложности (скорость растёт).
- **Заставка при запуске** — логотип «TETRIS» и ряд фигур, висит до нажатия любой клавиши.
- **Предпросмотр следующей фигуры** и панель счёта/уровня.
- **Переназначение клавиш** — интерактивное меню настройки, сохраняется в `tetris_settings.ini`.
- **Отрисовка без мерцания** — двойная буферизация в обоих режимах: кадр рисуется в скрытый буфер, затем атомарно переключается активный буфер (в фиксированном — копирование основного буфера в резервный, в адаптивном — показ предыдущего кадра в резервном и рисование нового в основном).
- **Два режима консоли** — фиксированные 80×25 (классическая консоль, через `mode con`) и адаптивный (Windows Terminal и другие терминалы с псевдоконсолью: кадр 80×25 центрируется в окне, при слишком маленьком окне — окно-подсказка). Режим определяется автоматически при запуске.
- **16-цветная палитра** консоли.

## 🎮 Управление

| Действие | Клавиша по умолчанию |
|---|---|
| Влево | `←` |
| Вправо | `→` |
| Поворот против часовой стрелки | `↑` |
| Поворот по часовой стрелке | `↓` |
| Ускорение падения | `Пробел` |
| Выход в меню | `Esc` |

Все клавиши можно переназначить в меню настроек (пункт **2** главного меню). Назначения сохраняются между запусками.

В меню паузы `Esc` — то же, что пункт **2** («Продолжить»).

## 📁 Структура проекта

```
Tetris/
├─ Main.cpp              ← точка входа
├─ Core/                 ← игровая логика: Tetris, Game, Figure,
│                          FigureGenerator, GameData
├─ Rendering/            ← рендер: Console, GameField, Splash
├─ Input/                ← ввод и настройки: Keys, Settings
└─ Menu/                 ← меню: GameMenu
```

| Файл | Назначение |
|---|---|
| `Main.cpp` | Точка входа: `main()` — инициализация, загрузка настроек, заставка, цикл меню/партий |
| `Core/Tetris.h` / `Core/Tetris.cpp` | Игровой цикл, ввод; `Tetris.h` — объявление `PlayGame()` |
| `Rendering/Console.h` / `Rendering/Console.cpp` | Консоль: инициализация (`ProgramSettings()`), определение режима (фиксированный 80×25 / адаптивный для Windows Terminal и других pty-терминалов), двойная буферизация (`DoubleBufferingBegin/End`) |
| `Core/Game.h` / `Core/Game.cpp` | Правила игры: столкновения, движения, падение, очистка линий, счёт и уровни |
| `Rendering/GameField.h` / `Rendering/GameField.cpp` | Рендер поля: сборка кадра (`CreateGameField`) и вывод в консоль (`ViewGameField`) |
| `Rendering/Splash.h` / `Rendering/Splash.cpp` | Заставка при запуске: логотип «TETRIS» + ряд фигур, висит до нажатия любой клавиши (`ShowSplash`) |
| `Menu/GameMenu.h` / `Menu/GameMenu.cpp` | Меню: главное меню (`StartMenu`), возврат из игры (`ReturnToMenu`), очистка буфера клавиатуры (`ClearKeyboardBuffer`) |
| `Core/Figure.h` / `Core/Figure.cpp` | Класс `Figure` — падающая фигура: позиция, поворот, сдвиги |
| `Core/FigureGenerator.h` / `Core/FigureGenerator.cpp` | Генерация фигур: случайный id (`RandomFigureId`) и стартовая позиция (`PositionById`) |
| `Core/GameData.h` | Константы, таблицы фигур, энамы, раскладка поля (namespace `Tetris`) |
| `Input/Keys.h` | Виртуальные коды клавиш, действия, набор привязок |
| `Input/Settings.h` | Загрузка/сохранение настроек, интерактивная настройка клавиш |

## 🔧 Технологии

- **C++23** — `inline constexpr`, `inline`-функции в заголовках (header-only модули настроек).
- **WinAPI** — консольные буферы, `GetAsyncKeyState` для опроса клавиатуры.
- **Без внешних зависимостей** — только стандартная библиотека и Windows SDK.

## 🗺️ Дорожная карта

### 🎨 Заставки
Базовая заставка с логотипом уже есть (см. «Что уже есть»). Дальше — настоящая графика в консоли: **truecolor (24 бита)** через VT-последовательности + половинные блоки `▀ ▄ █` (двойное вертикальное разрешение). Пиксель-арт без внешних зависимостей.

### 🎵 Музыка
Два слоя, выбор по формату файла:

- **MCI** — MIDI (классика, системный секвенсор Windows, без зависимостей).
- **miniaudio** — MP3 / FLAC / OGG / WAV (один заголовок, MIT, поверх WASAPI).

### 👥 Два игрока
Одновременная игра на одной клавиатуре (удобные раскладки подберём по ходу). Поддержка геймпадов через **XInput** — единый API для Xbox, DualShock 4 и большинства USB-падов.

### 🌐 Сетевой режим
Игра на двоих по сети. Протокол: обмен **ходами** (движение / поворот / сброс) по **TCP** — мало трафика, просто. *Самое сложное — берём последним.*
